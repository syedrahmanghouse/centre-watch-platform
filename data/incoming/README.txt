CENTREWATCH — CCTV FOOTAGE INTAKE

Put classroom/workshop MP4, MOV, AVI, MKV, WebM, JPG, or PNG files in this folder.
Use one room/camera per file and names such as chennai_room01_session01.mp4.
Do not put passwords, RTSP credentials, or personal attendance rosters in filenames.

After copying: sign in as administrator, open Footage intake, and assign each file to its institution.
The institution head can then choose the assigned file when creating a class.
Other institutions cannot list or attach that file.

For each file, provide the room, reported count, true visible count at timestamps if known, and sanctioned equipment quantities.
Use ../annotations/manifest.example.json as the format guide, or provide the details in chat.
We will keep the originals local and exclude this folder from source publication.
